# Подбор автозапчастей

Клиент для веб-сервиса «Проценка» (favorit-parts): поиск производителей по артикулу и вывод предложений с аналогами.

Стек: React 18, Redux Toolkit, Bootstrap 5, Vite. Без TypeScript.

## Запуск

```bash
npm install
cp .env.example .env
npm run dev
```

Ключ API можно указать в `.env` (`VITE_API_KEY`) или ввести прямо в интерфейсе.

Запросы идут через прокси Vite (`/api` → `http://api.favorit-parts.ru/hs/hsprice`), так как API работает по HTTP и не отдаёт CORS-заголовки.

## Как работает

1. Ввод артикула — через 600 мс после остановки ввода уходит запрос `number=...`, из ответа собирается список уникальных производителей.
2. Выбор производителя — запрос `number=...&brand=...&analogues=on`, результат выводится таблицей: производитель, артикул, наименование, склад, цена, остаток, дата отгрузки. Аналоги помечены бейджем.

Состояния загрузки показываются лоадерами, ошибки API и сети — сообщением с кнопкой «Повторить». Пустые ответы обрабатываются отдельно. Устаревшие запросы отменяются через `AbortController`.

## Структура

```
src/
  api/partsApi.js         запросы к API и разбор ошибок
  store/                  brands, offers, settings слайсы
  components/             форма поиска, список брендов, таблица, лоадер, ошибка
```
